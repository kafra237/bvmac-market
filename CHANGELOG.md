# Project history

This repository starts from the first cleaned community baseline of BVMAC Market.

Earlier development was iterative and production-oriented. The community cleanup consolidated that work into a stable source tree, removed release-specific deployment artefacts, unified authenticated pages under `/app`, added browser/PWA release discovery, completed the EN/FR translation layer, introduced targeted communication campaigns, added the 30-minute publication watcher and documented the validated Predictive Radar models.

From this point forward, Git commits, pull requests and GitHub releases should be used as the project history rather than copying old deployment packages into the repository.
