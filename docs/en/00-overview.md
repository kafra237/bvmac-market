# Project overview

BVMAC Market exists to make public BVMAC information easier to follow over time. The official PDF bulletin remains the source; this project downloads it, extracts structured tables, keeps snapshots in PostgreSQL and exposes them through a web interface.

For a non-technical reader, the project can be thought of as a library with an automatic librarian: the pipeline collects new documents, the database keeps the catalogue and history, the backend answers questions, and the web interface turns the answers into readable screens.

The main functional areas are market browsing, virtual portfolios, alerts, RSS/public notices, weekly reports, first-party usage analytics and the Predictive Radar.
