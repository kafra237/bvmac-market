# Web interface / Interface web

This folder contains the browser application: HTML views, CSS, JavaScript, charts, the bilingual FR/EN layer and PWA assets. Authenticated features share the canonical `/app?view=...` entry point; login, public information and administration keep dedicated routes because they have different security roles.

Ce dossier contient l’application navigateur : vues HTML, CSS, JavaScript, graphiques, traduction FR/EN et PWA. Les fonctions connectées passent par `/app?view=...`; la connexion, les informations publiques et l’administration gardent des routes distinctes pour des raisons de sécurité.
