# Predictive Radar / Radar prédictif

This folder contains production inference, serialized models, validation metadata and the model card. The retained targets are probabilistic and are shown with confidence information. Exact-price forecasting and unstable targets are deliberately rejected.

Ce dossier contient l’inférence de production, les modèles sérialisés, les métadonnées de validation et la model card. Les cibles retenues sont probabilistes et affichées avec un niveau de confiance. Les prédictions de prix exact et les cibles instables sont volontairement rejetées.

Start with [`MODEL_CARD.md`](MODEL_CARD.md), then read [`docs/en/06-machine-learning.md`](../docs/en/06-machine-learning.md) or [`docs/fr/06-machine-learning.md`](../docs/fr/06-machine-learning.md).
