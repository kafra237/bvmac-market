# Operations / Exploitation

These Python helpers support server maintenance: backup verification, monitoring, VAPID key generation, admin password reset, new-data push delivery, Nginx route patching and the lightweight bulletin watcher. They are internal helpers; operators normally use only the root `deploy.sh` and `checking.sh` commands.

Ces outils Python servent à l’exploitation : vérification des sauvegardes, supervision, clés VAPID, mot de passe admin, push de nouvelles données, routage Nginx et détection légère des nouveaux bulletins. Ils sont internes ; un opérateur utilise normalement seulement `deploy.sh` et `checking.sh` à la racine.
